A curated list of the software and hardware I use on both machines. My general philosophy: prefer free and open-source software that's minimal, effective, and efficient at the one job it's meant to do.

Operating Systems + Desktop

PC — Manjaro + KDE Plasma

Manjaro · KDE Plasma · Konsole

Manjaro, an Arch-based distro that's never given me a real problem, so I never left. I stick to Pacman and a select few AUR packages and avoid Flatpak/Snap/AppImage to keep things simple. On the desktop I run Plasma with kwin and Konsole — for a less minimalist, but cleaner experience.

Laptop — Manjaro + Sway

Manjaro · Sway · foot

Same distro, different window manager: a ThinkPad X1 Carbon (Gen 10) running Sway, a tiling Wayland compositor, with foot as the terminal and zsh as the shell. Tiling makes far better use of a smaller laptop screen than a floating desktop would.

I connect the two over Netbird, a WireGuard-based mesh VPN. Allows me to ssh between my PC and laptop wherever I'm working from, without opening ports on my home network.

General Software

Web browser
Firefox, with a lightly edited copy of the arkenfox user.js for privacy hardening, plus uBlock Origin to block ads and trackers. ungoogled-chromium occasionally when something needs a Chromium engine.
Search engine
DuckDuckGo — Will there ever be a perfect search engine? This will do for now.
IDE
VSCode — I would use VSCodium but the remote development features are too useful.
PDF viewer
sioyek — a keyboard-driven, minimal PDF viewer built for comfortably reading technical papers.
Text editor
Neovim — beautiful vim-based text editor.
